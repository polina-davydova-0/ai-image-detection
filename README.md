## Основные результаты (Этап 2 — Семестр 7)

### 1. Расширенная база данных (`dataset_extended`)
Сформирована база данных из **15 524 фрагментов** размером `256×256` пикселей без сжатия (`PNG`):
* **Реальные изображения (`Real`):** 8 068 фрагментов (нарезаны из 51 оригинального снимка без постобработки).
* **Синтетические изображения (`AI`):** 7 456 фрагментов от **6 генераторов** разных архитектурных семейств (`SD 1.5`, `SDXL`, `DDPM`, `YandexART`, `StyleGAN2-ADA`, `VAE`).
* Дополнительно сформированы тестовые наборы со сжатием **JPEG 95%, 90% и 80%**.

### 2. Обученный детектор на базе `ResNet50V2` (бинарная классификация)
* **Общая точность (Accuracy)** на тестовой выборке (2329 фрагментов): **95,84%** (`F1-score = 0,96`, `ROC-AUC = 0,9830`).
* **Точность по генераторам:** `DDPM` — 100,00%, `SDXL` — 99,96%, `YandexART` — 99,57%, `SD 1.5` — 99,38%, `StyleGAN2` — 99,00%, `VAE` — 66,08%.
* **Устойчивость к JPEG-сжатию** (на единой тестовой выборке из 2329 фрагментов):
  * Без сжатия (`PNG`): **95,84%**
  * Качество JPEG 95%: **95,96%**
  * Качество JPEG 90%: **95,84%**
  * Качество JPEG 80%: **95,75%** (снижение всего на 0,09%)

### 3. Идентификация источника генерации (7 классов)
Выходной слой `ResNet50V2` модифицирован под многоклассовую классификацию на $L + 1 = 7$ классов (`Real` + 6 генераторов, активация `Softmax`):
* **Общая точность разделения на 7 классов (Accuracy):** **94,43%** (`Macro F1 = 0,93`, `Weighted F1 = 0,94`).
* Построена нормализованная матрица перепутывания $7 \times 7$, подтверждающая высокую разделимость генеративных моделей.

## Результаты предыдущего этапа (Этап 1 — Семестр 6)

На первом этапе проводилось тестирование готовых предобученных детекторов (`AIorNot-SigLIP2`, `AI-image-detector`, `AI-vs-Deepfake-vs-Real-Siglip2`) на собственной выборке из 260 изображений и наборе `Tiny GenImage`:
* Лучший готовый детектор (`AI-vs-Deepfake-vs-Real-Siglip2`) показал точность **67,69%** на собственной БД и от **37% до 53%** на современных генераторах `Tiny GenImage`, что обосновало разработку специализированного детектора на базе `ResNet50V2`.

## Как воспроизвести эксперименты

1. Скачайте архивы данных (`real_tiles.zip`, `ai_tiles.zip`) или готовые веса моделей (`.keras`) по прямой ссылке из [`LINKS.md`](./LINKS.md) или [папки на Google Диске]([https://google.com](https://drive.google.com/drive/folders/1ILgTBHOLH9Nm1rqpZAKv0NRrubqx_kR6?usp=sharing)).
2. Для локальной подготовки данных установите зависимости:
   ```bash
   pip install rawpy imageio pillow numpy tqdm
   ```
3. Для обучения и оценки нейросетевых моделей откройте ноутбуки из папки [`notebooks/`](./notebooks) в Google Colab (используются `tensorflow`, `scikit-learn`, `matplotlib`, `seaborn`).
